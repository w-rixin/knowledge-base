# 麒麟 aarch64 安装包 — 推送操作清单

本地已全部就绪，你只需完成 4 步。**不需要有 Linux 机器、不需要装任何开发环境。**

---

## 第 1 步：在 GitHub 网页新建仓库

打开 https://github.com/new

| 字段 | 填什么 |
|---|---|
| Owner | 你的账号 |
| Repository name | `knowledge-base`（或任意名字） |
| Description | 留空即可 |
| **Public / Private** | 见下方说明 |
| 勾选项 | **四个勾全部不要勾**（尤其不要勾 README / .gitignore / license） |

### 公开还是私有？

- **Public（公开）**：ARM runner **免费无限量**，且可用 `ubuntu-24.04-arm` 原生 runner。
  代码会公开。
- **Private（私有）**：ARM runner 从 2026 年 1 月起也支持，但**消耗你的 Actions 免费额度**
  （私有仓库免费额度是 2000 分钟/月，一次 ARM 构建约 20-30 分钟）。

> 如果代码不方便公开但额度紧张，可以先 Private 验证一次，确认能跑通再决定。

建好后页面会显示一个地址，形如：

```
https://github.com/你的用户名/knowledge-base.git
```

**把这个地址记下来**，下一步要用。

---

## 第 2 步：添加远程地址并推送

在 **PowerShell** 或 **Git Bash** 里执行（把 `<你的用户名>` 换成实际用户名）：

```bash
cd D:\WorkProject\knowledge-base-1.65.0

git remote add origin https://github.com/<你的用户名>/knowledge-base.git

git push -u origin master
```

推送时 GitHub 会要求认证，选一种：

| 方式 | 操作 |
|---|---|
| **浏览器登录**（推荐） | 提示时选 "Sign in with your browser"，复制一次性验证码到浏览器完成授权 |
| Personal Access Token | 密码位置粘贴 PAT（需 `repo` 权限） |

> 如果 push 时提示没有权限，说明仓库名或用户名填错了，
> 回第 2 步核对 `git remote -v` 输出的地址。

**推送成功后**，仓库里应该能看到 `src-tauri/`、`docs/`、`scripts/` 等目录。

---

## 第 3 步：触发麒麟 aarch64 构建

推送成功后，在同一个终端执行：

```bash
bash scripts/build-kylin.sh
```

脚本会先做 7 项预检（git / Node / 仓库 / 远程 / CI 配置 / 打包配置 / 工作区），
全绿后提示确认，输 `y` 回车即可。

它做的事等价于：

```bash
git tag v1.65.0-kylin
git push origin v1.65.0-kylin
```

---

## 第 4 步：等构建完成，下载 deb

**约 10-20 分钟**。查看进度：

- 打开仓库 → **Actions** 标签页 → 看 `Release` 工作流
- 确认 `麒麟 aarch64`（ubuntu-24.04-arm）那个 job 是绿色 ✔

构建完成后产物在 **草稿 Release** 里（草稿状态不会直接显示，需要先发布）：

**方式 A：网页发布后下载**
1. 仓库 → **Releases** → 点最新那条草稿
2. 点 **Edit draft**（铅笔图标）→ 填个标题 → **Publish release**
3. 下载 `KnowledgeBase_1.65.0_arm64.deb`

**方式 B：命令行下载**（推荐，省去发布步骤）
```bash
gh release download v1.65.0-kylin --pattern "*_arm64.deb"
```

> ⚠️ **务必核对文件名后缀是 `_arm64.deb` 或 `_aarch64.deb`**。
> 如果下载到的是 `_amd64.deb`，说明拿到 x86_64 产物，麒麟机上装不上。

---

## 拿到 deb 之后

deb 文件需要连同它的依赖一起搬到不能联网的麒麟机上。

**如果有另一台联网的同版本麒麟机**，在那台机器上执行：

```bash
bash scripts/collect-offline-deps.sh --deb ~/Downloads/KnowledgeBase_1.65.0_arm64.deb
```

它会自动备齐 `libwebkit2gtk-4.1-0` 等依赖、生成本地源索引和安装说明，
然后把整个 `kb-offline-repo` 目录拷到 U 盘，摆渡到离线麒麟机即可安装。

**详细步骤见** `docs/kylin-aarch64-offline-deploy.md`。

---

## 可能遇到的三个问题

### 1. Actions 里找不到 ARM job

仓库 **Settings → Secrets and variables → Actions → Variables** 里
若存在 `RELEASE_KYLIN_ARM` 且值为 `skip`，ARM 构建被跳过了。
删掉该变量或改成 `build` 即可。

### 2. ARM job 报 webkit2gtk 相关错误

说明 `release.yml` 没推上去。确认第 2 步的 push 真的成功了。

### 3. deb 装不上，提示缺 libwebkit2gtk-4.1-0

**这是预期内的最大风险**，不是配置错误。Tauri 2 硬依赖 webkit2gtk-4.1，
而麒麟 V10 SP1/SP2 官方源只有 4.0。

应对：
- 优先确认麒麟版本能否升到 **SP3**（较新基线自带 4.1）
- 或从麒麟开发者社区获取 `webkit2gtk-4.1` 的 aarch64 deb 包，
  连同 `scripts/collect-offline-deps.sh` 一起放到联网机上收集

> 这个包能不能拿到，决定项目能否在麒麟上运行。
> 建议在推 tag 之前，先跟 IT 部门确认这个包的来源。
